# =============================================================================
# Pinned dependencies — landslide susceptibility & decision intelligence
# =============================================================================
# Every version below is pinned exactly, and this set was resolved and
# verified together  (Python 3.12, linux-x86_64).
#
# Why exact pins rather than ranges:
# The previous version of this project shipped no requirements file at all.
# Its saved models became unloadable once the local scikit-learn and CatBoost
# versions moved on, because pickled estimators embed class layouts that do not
# survive a major version bump. A susceptibility model you cannot load is a
# susceptibility model you cannot defend, so the lockfile is treated as part of
# the deliverable rather than as packaging hygiene.
#
# Install:
#     pip install -r requirements.txt
#
# Verify:
#     python run_pipeline.py check
#
# NOTE: TensorFlow/Keras are deliberately absent. The previous architecture
# included an ANN base learner; the rebuilt design uses gradient-boosted trees
# on thematic feature subsets instead, which removes a ~600 MB dependency and
# a substantial source of nondeterminism.
# -----------------------------------------------------------------------------
